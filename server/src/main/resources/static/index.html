连接说明

  1. 手机与电脑连同一个 WiFi；
  2. 手机扫上面的二维码，或在浏览器输入局域网地址 + /visitor/；
  3. 安卓 App 首次启动，用 App 内的「扫码连接服务器」扫同一个二维码；
  4. 连不上时检查 Windows 防火墙是否放行 Node / Java 进程。
