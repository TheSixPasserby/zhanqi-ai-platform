## 关键判断

**① 坐标用 0-100 百分比，不用像素。**
地图要能缩放平移，百分比坐标在任何缩放级别下都不用换算，窗口尺寸变化也不会错位。
若存像素，就得同时存参考分辨率，换设备必错位。

**② 底图用 SVG 画，不用位图。**
这张地图的核心用法就是「放大看细节」—— 位图放到 3 倍就糊了，SVG 是矢量，任意缩放都清晰，
而且底图数据只有几 KB，离线可用（符合项目不许 CDN 的红线）。
底图按战旗村实际形态画：都江堰水系引来的水渠、川西林盘、连片农田、十八坊街区、村口广场。

**③ 视图变换只维护一套公式。**
第一版我把 `applyView` 的 transform 拼接写乱了（拼了四段 translate/scale），
`toMapCoord` 又用了另一套近似换算 —— 缩放后选点会漂。
改成唯一模型：`视口坐标 = (世界坐标 − t) × k`，反解 `世界坐标 = 视口 / k + t`，
缩放、拖拽、选点全部复用这两个式子。

**④ 选点用「再点同一处取消」，不是「点第二下取消任意位置」。**
需求说的是「再次点击可取消」。如果做成「下一次点击无条件取消」，
用户想微调位置时点一下反而清空了，很难用。判定为距上次点 <6% 才取消。

**⑤ 主题仍是只覆盖设计令牌。**
新增 `warm`（陶土朱，暖色）与 `ink`（黛青，冷色），做法与 `theme-dark` 完全一致：
在 `html[data-theme=...]` 上重定义那批 CSS 变量。4 套主题共用同一套组件样式，
所以卡片、弹窗、表格、输入框必然一起变 —— 这也是需求「不能只改局部」的保证方式。

## 踩过的坑（都花了时间，记下来）

**① 管理端「个性化设置」空白，根因是组件作用域。**
面板写在 `viewServer` 子组件的模板里，但 `themeMode` / `setTheme` 我只加在了**根 Vue** 上。
子组件读不到父组件的 data，模板里两个变量都是 undefined —— 面板能显示框架，内容是空的。
修法：在 `viewServer` 自己也持有一份，并向 `ZQTheme` 订阅。
**教训：Vue 2 的模板只能访问本组件实例的属性，写在父组件不等于子组件能用。**

**② 模板插错位置，整页不渲染。**
我给 PC 端加 `map`/`plan` 两个 `v-else-if` 分支时，用了两次文本替换，
第一次其实已成功（后一步报错让我误以为失败又重做了一遍），结果块重复了两份；
而去重时又按「移到 mine 之前」计算，实际上块本来就在正确位置。
表现是：`view === 'map'` 但页面仍渲染首页 —— 因为 `v-if` 链在重复块处断了。
**教训：大文件插入模板后必须校验 `view 分支列表` 与 `template 开闭计数`，不能只看替换是否返回成功。**

**③ 模板里引用了不存在的方法，整个分支渲染失败。**
地图侧栏我写了 `@error="imgFail"`，但 `pc.js` 里没有这个方法。
Vue 渲染期抛错 → 该分支渲染中断 → 页面空白，而控制台只有一条 `imgFail is not defined @render`。
**排查方法：装 `Vue.config.errorHandler` 收集渲染错误，比看控制台日志准。**
**预防方法：改完模板拿模板里的 `@click`/`@error` 函数名与 js 里的方法名做一次差集检查。**

**④ 管理端页面漏引 `virtual-map.js`，地图静默不出现。**
`initPickMap` 里有 `if (!box || !window.ZQMap) { return; }` 这层守卫，
所以缺脚本时它**静默返回**，不报错 —— 商品/活动位置回填正常（数据层没问题），
只是地图不画。这类「守卫吃掉错误」的写法排查成本很高。
**教训：加兜底守卫时，至少在 dev 用 `console.warn` 提示一次，别完全静默。**

**⑤ Element UI 的 dialog 打开后 DOM 不是立刻可用。**
`editVisible = true` 后立刻 `$nextTick` 拿 `$refs` 有时仍拿不到，加 80ms 延迟才稳定。

**⑥ 测试脚本自身的引号转义反复出错。**
浏览器表达式里套 JSON、又套 JS 字符串，多层转义后极易写出语法错误，
我至少三次把测试脚本写坏、误以为是产品 bug。
**做法：把浏览器端表达式单独存成 `.txt` 文件再用 `fs.readFileSync` 读进来求值，彻底避开多层转义。**

## 遗留

1. **地图底图是艺术化示意，不是测绘级**：按村落相对方位布局，不能当导航用。
   若要做真地图，得接第三方地图 SDK，与「离线可用」红线冲突，需要产品决策。
2. **坐标只到 0.01 精度**（两位小数），足够村域尺度；若将来要精确到单栋建筑需改精度。
3. **底图未做缩放级别切换**（没有「放大后显示更细的标注」这类分级渲染），
   目前所有信息一次画完，缩到最大时标记会略显密集。
