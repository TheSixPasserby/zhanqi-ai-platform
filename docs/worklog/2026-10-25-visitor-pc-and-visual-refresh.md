- 日期：2026-10-25

- 涉及：`static/assets/img/photos/*`（18 张写实图）、`static/assets/img/icons.svg`、

## 一、图片：从 SVG 插画换成写实照片

原来 14 个点位和 27 个商品共用 14 个手绘 SVG，视觉上偏「示意图」，
同一张 `craft.svg` 同时代表香囊、豆瓣、竹编，看图分不出商品。

这次用 AI 生成了 **18 张写实照片**（川西乡村实景风格）：

| 类别 | 数量 | 说明 |
| --- | --- | --- |
| 点位/场景 | 12 | 服务中心、林盘、布鞋坊、稻田、村史馆、研学基地、萝卜田、书屋、豆瓣晒场、茶舍、竹编铺、银杏院 |
| 商品特写 | 6 | 大米、豆瓣、布鞋、民宿客房、九大碗、盖碗茶 |

**为什么不直接用「实拍」**：项目要求离线部署、不引外链，且没有战旗村的真实照片。
这里用的是 AI 生成的**写实摄影风格**图，不是当地实拍。要换成真实照片，
把文件覆盖到 `static/assets/img/photos/` 同名即可，代码不用动。

处理流程（`logs/process-photos.py`）：

1. 生成的原图右下角有平台水印，统一**裁掉底部 62px**；
2. 缩到 1200px 宽、转 JPG（质量 84、progressive），18 张共 **4.0 MB**；
3. 按语义重命名（`spot-*.jpg` / `goods-*.jpg`），删掉 PNG 原图。

`seed.sql` 里 96 条记录的 `cover` 按**记录 id** 精确替换（不是全局替换）——
因为 `craft.svg` / `farm.svg` 被多种商品共用，全局替换会把竹编和豆瓣换成同一张图。
订单表的封面快照也一起换了，否则订单列表还是旧插画。

## 二、图标：一套 SVG sprite 替代所有「文字顶替图标」

新增 `static/assets/img/icons.svg`，29 个线性图标（24×24、1.8 描边、圆角端点），
三端用 `<use href="...icons.svg#i-xxx">` 引用，颜色跟随 `currentColor`。

替换掉的位置：

- 游客端（手机版）：功能宫格 6 个 `glyph` 单字、底部 tabbar 4 个单字、
  「我的」页菜单 6 个单字、右箭头 `›`；
- 游客端（电脑版）：导航、快捷入口、按钮、抽屉操作全部用图标；
- uni-app（安卓）：宫格与「我的」菜单原本也是单字，App 端不支持外部 SVG sprite，
  所以用 Chrome 把同一套图标渲染成 **PNG**（`src/static/icons/*.png`，2 倍图、透明底、品牌绿）。

**保留的单字**：印章上的「旗 / 院 / 鞋 / 稻」等。那不是「用文字顶替图标」，
而是印章本身的视觉语义（真印章就是刻字），换掉反而失真。

## 三、游客端电脑版

新增 `/visitor/pc/`（`index.html` + `pc.css` + `pc.js`），与手机版**同一套接口、同一套配色变量**，
布局按宽屏重做：顶部导航 + Hero + 4 列商品网格 + 左侧分类筛选 + 右侧抽屉详情。

功能覆盖：登录/注册、首页、点位列表与打卡、点位详情与语音讲解、
商城与商品详情、购物车下单、订单列表与取消、活动日历、AI 问答与行程规划、个人中心与印章墙。

### 设备检测（双向）

- `/visitor/`（手机版）：`!移动 UA && 宽度 ≥900 && pointer:fine` → 跳 `/visitor/pc/`
- `/visitor/pc/`（电脑版）：移动 UA 或宽度 ≤820 → 跳回 `/visitor/`
- 手动切换带 `?pc=0` / `?pc=1`，会写 `sessionStorage`，本次会话不再来回跳

### 踩到的坑：新目录必须显式 forward

`WebConfig` 只给 `/admin`、`/merchant`、`/visitor` 配了「目录 → index.html」的转发。
Spring 不会把 `/visitor/pc/` 自动当目录首页，访问会落到
`{"ok":false,"error":"资源不存在：visitor/pc"}`。
补了 `/visitor/pc` 的重定向与 `/visitor/pc/` 的 forward 才通。

## 五、遗留

1. **uni-app 端只改了源码，没有重新打包**。本机 npm 不可用，无法执行
   `npm run build:app`；下次在有 npm 的机器上重新打包，PNG 图标才会进 APK。
2. 电脑版暂未实现「研学民宿」独立页（`booking`），预约类商品仍可在商城下单；
   手机版保留完整入口。若需要，按商品详情加日期/人数选择即可。
3. 18 张图是 AI 生成，若某张与真实商品差距较大，直接覆盖同名文件即可替换。
